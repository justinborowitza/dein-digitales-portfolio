# Portfolio-Texte

Für deutsche, öffentlich sichtbare Portfolio-Texte nutze den lokalen Skill `.agents/skills/portfolio-humanizer/SKILL.md`. Er enthält Justins Schreibpräferenzen, das kurze Kartenformat und die Grenzen belegter Projektangaben. Für reine Code- oder Designänderungen ohne Textarbeit ist er nicht erforderlich.

`PROJECT-CONTENT.md` dokumentiert die Projektquellen. Texte auf der bestehenden Website sind keine unabhängigen Sprachproben von Justin. Änderungen an einem Skill allein veröffentlichen die Website nicht.
