# Microsoft product icons

These icons identify Microsoft technologies in project documentation, with product names displayed alongside. The SVG files retain their original colors, proportions and shapes.

- Power Apps, Power Automate and Power Pages: [Microsoft Power Platform icons](https://learn.microsoft.com/en-us/power-platform/guidance/icons), [official download](https://download.microsoft.com/download/498606aa-6d27-4f13-aa5c-1401078c153b/Power-Platform-icons-scalable.zip).
- Power BI: [Microsoft Fabric icons](https://learn.microsoft.com/en-us/fabric/fundamentals/icons), [official Microsoft repository](https://github.com/microsoft/fabric-samples/blob/main/docs-samples/Icons.zip), file `v6.1.0/package/dist/svg/power_bi_48_color.svg`.

Microsoft retains ownership. Use is subject to the terms on the linked official documentation pages; the icons must not be cropped, rotated, distorted or used to represent this portfolio's own brand.
